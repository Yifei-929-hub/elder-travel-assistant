# 🧓 老人出行小助手（Dify 工作流）

一个面向老年人的 AI 出行助手，基于 [Dify](https://dify.ai) 的 Chatflow 搭建，接入 **高德地图** 和 **12306** 实时数据。

老人只要说一句「**11月12日从上海去杭州玩3天**」，助手就像旅行社一样给出一整份行程单：

- 🚄 **往返车票**：推荐车次、几点出发几点到、历时、二等座票价、有没有票（12306 实时）
- 🗓️ **每日安排**：上午、中午、下午、晚上各做什么，怎么去，步行多久，大约花多少钱
- 🏨 **住宿建议**：交通方便的酒店，以及附近的医院
- 🧥 **穿衣和行李**：按真实天气和天数算出带几件衣服，还有常用药、证件清单
- ⚠️ **注意事项**：结合目的地、季节和身体情况的提醒，含防骗提醒
- 💰 **费用估算**：交通、门票、住宿、餐饮、其他，每人合计

平时也能单独问：「下周三上海到北京有哪些高铁」「人民广场到虹桥火车站怎么坐地铁」「我住望湖宾馆，附近有药店吗」「我有高血压，冬天出门要注意什么」。

> **谁来配置？** 通常是子女、社区或养老机构的工作人员配置一次，再把链接发给老人。老人本人只需要打开链接、打字提问。

## 工作原理

```
用户提问 ──► 获取今天日期 ──► 判断老人想做什么 ──┬─► 写旅游攻略（Agent：高德 + 12306）──► 回复
                                               ├─► 查票买票指导（Agent：高德 + 12306）──► 回复
                                               ├─► 出行健康提醒（Agent：高德）       ──► 回复
                                               └─► 陪聊与引导                        ──► 回复
```

- Agent 节点会根据问题自己决定调用哪些工具：查车站、查车次、查天气、搜酒店、找医院、规划路线。
- 每个分支记住最近 10 轮对话，「那后天呢」这样的追问也能接上。
- 回答要求短句、分步骤、不用英文和专业词。

## 快速开始

1. 注册 [Dify 云版](https://cloud.dify.ai)，也可以自己部署 Dify。
2. 下载 [`dsl/elder-travel-assistant.yml`](dsl/elder-travel-assistant.yml)，在 Dify「工作室」点 **导入 DSL 文件**，按提示安装插件。
3. 在「集成 → 模型供应商」填入 **DeepSeek** 的 API Key（或[换成别的模型](docs/02-更换大模型.md)）。
4. 在「集成 → MCP」添加 **高德地图**（标识 `amap`）和 **12306 查票**（标识 `train12306`）两个 MCP 服务。
5. 点 **预览** 试一试，再点 **发布**，把网页链接发给老人。

## 能做什么，不能做什么

| | 说明 |
|---|---|
| ✅ 能 | 生成完整行程单；查实时车次、票价、余票；查天气、景点、酒店、附近医院药店、公交地铁路线；健康和防骗提醒 |
| ⚠️ 估算 | 门票、住宿、餐饮价格由模型估算并标明「估算」；超过约 4 天的天气按季节估计 |
| ⚠️ 暂不支持 | 机票的航班和价格（需要另接付费的航班数据服务） |
| ❌ 不能、也不会做 | 替老人登录 12306 或航空公司账号、下单、付款。12306 没有开放下单接口，用程序代登录会违反规定，也会给账号和钱带来风险 |

## 安全与隐私设计

- 助手**从不索要**身份证号、银行卡号、密码、验证码；老人主动发来时，会提醒不要发，也不会在回答里重复这些号码。
- 讲买票时会提醒：12306 和航空公司**不会**打电话让人「退票改签」还转账。
- 健康分支声明「不是医生」，换药、调整剂量等问题都建议先问医生；遇到急症，第一句话就提醒拨打 120。
- 本仓库**不包含任何密钥**。模型 Key、高德 Key、MCP 地址都只填在部署者自己的 Dify 里，导出工作流时也不会带出。

## 用量参考

使用 `deepseek-v4-flash`：一份 3 天完整行程约 5～9 万 token、1～3 分钟；普通问答几千 token。详见 [04](docs/04-接入实时数据.md#用量参考)。

## 常见问题

**能直接用别人发布的链接吗？**
不建议。每个 Dify 应用用的是发布者自己的模型 Key，用别人的链接等于花别人的钱。请按「快速开始」导入到你自己的 Dify，填你自己的 Key，再把你自己的链接发给家里老人。

**能不能做成一个链接，让每个用户在网页上填自己的 Key？**
Dify 已发布的应用不支持让访客填 Key。硬做的话，Key 会被记进发布者的日志，很不安全，而且自带的 Key 没法让 Agent 节点调用高德和 12306。所以本项目采用「每个家庭自己部署一份」的方式。

**老人自己需要申请 Key 吗？**
不需要。由会用电脑的家人部署一次，老人只用打开链接聊天。

## 自定义

所有提示词都在 Dify 画布的各个节点里，点开节点就能直接修改，比如：

- 在「写旅游攻略」里调整节奏，例如每天只去 1 个景点；
- 在「陪聊与引导」里改称呼，例如称「王阿姨」；
- 在「开始」节点加输入项（常住城市、身体情况、紧急联系人），让每次回答更贴合本人。

改完后在 Dify 中导出 DSL，替换本仓库的 yml，欢迎提交 PR。
