# 02 更换大模型

工作流默认使用通义千问。你也可以换成任何在 Dify 里配置好的对话模型，例如 DeepSeek、Kimi、智谱、OpenAI、Claude、Gemini。

## 需要修改的 5 个节点

| 节点 | 默认模型 | 建议 |
|---|---|---|
| 判断老人想做什么 | qwen3.6-flash | 用便宜、快的小模型即可 |
| 写旅游攻略 | qwen3.6-plus | 用效果好的主力模型 |
| 查票买票指导 | qwen3.6-plus | 用效果好的主力模型 |
| 出行健康提醒 | qwen3.6-plus | 用效果好的主力模型 |
| 陪聊与引导 | qwen3.6-flash | 小模型即可 |

## 步骤

1. 先在 **设置 → 模型供应商** 中安装并配置你要用的模型（填 API Key）。
2. 回到画布，逐个点击上面 5 个节点。
3. 在节点右侧面板顶部的 **模型** 下拉框里，选择新模型。
4. 点 **预览** 测试，再点 **发布 → 更新**。

## 选模型的小建议

- 中文表达好、价格低的国产模型（通义、DeepSeek、Kimi、智谱）通常很合适。
- 以后接入实时数据（见 [04](04-接入实时数据.md)）时，需要模型支持 **工具调用（Function Calling）**。主流模型基本都支持。
