# 01 导入到 Dify

## 1. 准备 Dify

二选一：

- **云版（推荐，最省事）**：打开 <https://cloud.dify.ai>，用邮箱、GitHub 或 Google 账号注册登录。
- **自己部署**：按 [Dify 官方文档](https://docs.dify.ai) 用 Docker 部署。版本需要 **1.6 或更高**。

## 2. 导入工作流

1. 下载本仓库的 [`dsl/elder-travel-assistant.yml`](../dsl/elder-travel-assistant.yml)。
   在 GitHub 页面打开文件后，点右上角的「Download raw file」下载按钮。
2. 进入 Dify **工作室**，点击 **导入 DSL 文件**（在「创建应用」区域）。
3. 选择刚下载的 yml 文件，点击 **创建**。
4. 如果 Dify 提示「缺少插件」，点击 **安装**。工作流默认使用 **通义千问（Tongyi）** 模型插件。
5. 如果提示「DSL 版本较旧」，直接确认导入即可，不影响使用。

导入后会进入画布，可以看到 11 个节点：开始 → 获取今天日期 → 判断老人想做什么 → 四个分支 → 回复。

## 3. 配置模型

1. 点击右上角头像 → **设置** → **模型供应商**。
2. 找到 **通义千问**，填入你的 API Key（在阿里云百炼平台申请）。
   - Dify 云版的新账号通常带有一定的免费试用额度，可以先不填，直接试用。
3. 如果你想用别的模型，见 [02 更换大模型](02-更换大模型.md)。

## 4. 试运行

点击画布右上角 **预览**，试着输入：

- 帮我安排一个杭州三日游，走路不要太多
- 下周想坐高铁去北京看孙子，我不太会用手机，咋买票
- 我有高血压，夏天出去旅游要注意什么？

画布上会实时显示每一步经过哪个节点。如果某个节点变红，点开它查看错误，最常见的原因是模型没有配置好。
