# 04 接入实时数据（高德地图 + 12306）

工作流里的「写旅游攻略」「查票买票指导」「出行健康提醒」三个节点是 **Agent 节点**，会自动调用两组 MCP 工具查实时数据：

| MCP 服务 | 服务器标识（必须一致） | 提供什么 |
|---|---|---|
| 高德地图 | `amap` | 天气、景点和酒店搜索、周边医院药店、公交地铁和步行路线 |
| 12306 查票 | `train12306` | 车站代码、车次、出发到达时间、票价、余票、中转方案 |

> ⚠️ **MCP 服务的配置不会跟着 yml 文件导入**，每个人要在自己的 Dify 里添加一次。
> **服务器标识必须和上表完全一样**，工作流是靠这个标识找到工具的。

## 1. 安装 Agent 策略插件

导入工作流时如果提示缺少插件，点安装即可。也可以手动安装：Dify 顶部「Marketplace」搜索 **Dify Agent 策略**（`langgenius/agent`），点安装。

## 2. 添加高德地图 MCP

1. 打开 [高德开放平台](https://lbs.amap.com)，登录并完成开发者认证（个人即可）。
2. 进入「控制台 → 应用管理 → 我的应用」，创建一个应用，再点「添加 Key」，服务平台选 **Web服务**。
3. 在 Dify 左侧点「集成 → MCP」，点「添加 MCP 服务 (HTTP)」：

   | 栏目 | 填写 |
   |---|---|
   | 服务端点 URL | `https://mcp.amap.com/mcp?key=你的高德Key` |
   | 名称 | 高德地图 |
   | 服务器标识 | `amap` |

4. 点「添加并授权」。成功后能看到 15 个工具，例如 `maps_weather`、`maps_direction_transit_integrated`。

## 3. 添加 12306 查票 MCP

12306 查票用的是开源项目 12306-mcp，只能**查票**，不能下单。

1. 打开 [魔搭社区](https://modelscope.cn) 并登录，进入「MCP 广场」，搜索 **12306**。
2. 打开 12306-mcp，点「连接」，生成你自己的服务地址（Streamable HTTP 或 SSE 都可以）。
3. 在 Dify「集成 → MCP」再添加一个：

   | 栏目 | 填写 |
   |---|---|
   | 服务端点 URL | 魔搭生成的地址 |
   | 名称 | 12306查票 |
   | 服务器标识 | `train12306` |

4. 成功后能看到 `get-tickets`、`get-station-code-of-citys` 等 8 个工具。

也可以自己部署 12306-mcp，只要 Dify 能通过网址访问到即可。Dify 云版不能运行需要装在本机的 MCP 服务。

## 4. 检查

回到工作流画布，点开「写旅游攻略」节点，工具列表里应该能看到高德和 12306 的工具，并且没有红色报错。然后点「预览」，输入：

> 11月12日从上海去杭州玩3天，我和老伴两个人

正常情况下会得到一份完整行程单：往返车次和票价、每天的安排、酒店和附近医院、穿衣件数、行李清单、费用估算。

## 数据说明

- **车次、票价、余票**：来自 12306，实时数据。
- **天气**：高德只提供最近约 4 天的预报。出发日期更远时，助手会按季节估计，并提醒出发前再看一次天气预报。
- **门票、餐饮、住宿价格**：高德不提供，由模型估算，回答里会标「估算」。
- **机票**：暂未接入。需要接航班数据服务（例如飞常准），一般要付费。

## 用量参考

用 `deepseek-v4-flash` 测试时，一份 3 天的完整行程约需 10～15 次工具调用、5～9 万 token，耗时 1～3 分钟。普通问答只需要几千 token。

## 安全

- Key 只填在你自己的 Dify 里，**不要提交到 GitHub，也不要写进提示词**。
- 从 Dify 导出工作流时，MCP 地址和 Key 不会被导出。
