# 03 发布给老人使用

## 1. 发布

1. 在画布右上角点击 **发布**，再点 **发布更新**。
2. 在发布菜单里点击 **运行**，会打开一个网页聊天界面。这个网页的地址就是给老人用的链接。
3. 以后修改了工作流，每次都要重新 **发布** 才会生效。

> 链接是公开的：拿到链接的人都能使用，用量会算在你的模型额度上。不要把链接发到公开群里。

## 2. 放到老人手机上

- **微信**：把链接发给老人，教他们点开后，点右上角「…」→「在浏览器打开」。
- **放到手机桌面**（推荐）：用手机浏览器打开链接，在菜单里选「添加到主屏幕」或「添加到桌面」，以后点图标就能打开，像一个 App。
- 第一次使用时，最好在旁边陪老人试一两次。

## 3. 适老化设置建议

在 Dify 应用的 **概览 → Web App 设置** 里可以调整：

- **标题和图标**：改成老人熟悉的名字，比如「出行小帮手」。
- **隐藏工作流步骤**：如果网页上显示了「工作流运行过程」，关掉它，老人只需要看到回答。
- **开场白和推荐问题**：在画布右上角的「功能」里修改，写成老人最常问的问题，让他们点一下就能问。

在手机上，老人也可以把浏览器字体调大，看起来更清楚。

## 4. 常见问题

- **回答很慢**：把「判断老人想做什么」「陪聊与引导」两个节点换成更快的小模型。
- **答非所问**：在 Dify 的 **日志** 里看这次走了哪个分支；如果分错了，改「判断老人想做什么」节点的分类描述。
- **额度用完了**：去模型供应商那里充值，或者换成更便宜的模型（见 [02](02-更换大模型.md)）。
