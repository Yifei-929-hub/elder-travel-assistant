# 02 更换大模型

工作流默认使用 **DeepSeek `deepseek-v4-flash`**，价格便宜，并且支持工具调用。你也可以换成任何在 Dify 里配置好的对话模型，例如通义千问、Kimi、智谱、OpenAI、Claude、Gemini。

## 需要修改的 5 个节点

| 节点 | 类型 | 建议 |
|---|---|---|
| 判断老人想做什么 | 问题分类 | 用便宜、快的小模型即可 |
| 写旅游攻略 | Agent | 必须支持**工具调用**；想要行程质量更好，可换成更强的模型（如 `deepseek-v4-pro`），费用会更高 |
| 查票买票指导 | Agent | 必须支持工具调用 |
| 出行健康提醒 | Agent | 必须支持工具调用 |
| 陪聊与引导 | LLM | 小模型即可 |

## 步骤

1. 在「集成 → 模型供应商」中安装并配置你要用的模型，填入你自己的 API Key。
2. 回到画布，逐个点击上面 5 个节点，在右侧面板的 **模型** 下拉框里选择新模型。
3. 点 **预览** 测试，再点 **发布**。

## 注意：关掉「深度思考」

DeepSeek、通义等模型有「深度思考 / thinking」开关。**请保持关闭**，原因有两个：

- 打开后，模型的思考过程（经常是英文）会直接显示在老人看到的回答里；
- 打开后更慢、更贵。

在节点的模型设置里，把 `thinking` 参数关掉即可。本仓库的工作流默认已经关闭。
