# 04 接入实时数据（规划中）

> ⚠️ 本页是 **v0.2 / v0.3 的计划**，相关工作流还没发布到本仓库，下面的步骤也还没有在本工作流上完整验证。
> 当前版本的助手查不到实时数据，会提醒老人去官方渠道确认。

## 计划接入的数据

| 数据 | 来源 | 部署者需要准备 |
|---|---|---|
| 天气、景点搜索、路线规划、附近医院和药店 | 高德地图官方 MCP 服务 | 在 [高德开放平台](https://lbs.amap.com) 注册，创建「Web服务」类型的 Key（个人开发者有免费额度） |
| 火车票车次、余票 | 开源的 12306 查票 MCP（只能查票，不能下单） | 找一个能用网址访问的托管版本（例如魔搭社区 MCP 广场），或自己部署 |
| 航班动态（可选） | 飞常准等航班数据 MCP | 申请对应平台的 API Key |

## 原理

Dify 1.6 起支持 MCP（模型上下文协议）。接入分两步：

1. **在 Dify 中添加 MCP 服务**：工具 → MCP → 添加 MCP 服务，填入服务地址（HTTP 或 SSE）。
2. **在工作流中使用**：把「写旅游攻略」「查票买票指导」等节点换成 **Agent 节点**，勾选这些 MCP 工具，模型会在需要时自动去查。

## 注意

- **MCP 配置不会跟着 yml 文件导出导入**，它保存在每个人自己的 Dify 工作区里。所以导入新版工作流后，需要按文档自己添加一次 MCP 服务。
- **Key 只填在你自己的 Dify 里**，不要提交到 GitHub，也不要写进提示词。
- Dify 云版只能连接能通过网址访问的 MCP 服务，不能运行需要在本机安装的服务。

欢迎在 Issue 里分享你接入成功的配置。
