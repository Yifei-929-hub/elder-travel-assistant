# 01 导入到 Dify

## 1. 准备 Dify

二选一：

- **云版（推荐，最省事）**：打开 <https://cloud.dify.ai>，用邮箱、GitHub 或 Google 账号注册登录。
- **自己部署**：按 [Dify 官方文档](https://docs.dify.ai) 用 Docker 部署。建议使用最新版本，最低 **1.6**（支持 MCP）。

## 2. 导入工作流

1. 下载本仓库的 [`dsl/elder-travel-assistant.yml`](../dsl/elder-travel-assistant.yml)。
   在 GitHub 页面打开文件后，点右上角的「Download raw file」下载按钮。
2. 进入 Dify **工作室**，点击 **导入 DSL 文件**。
3. 选择刚下载的 yml 文件，点击 **创建**。
4. 如果 Dify 提示缺少插件，点击 **安装**。工作流用到两个插件：
   - **DeepSeek** 模型插件
   - **Dify Agent 策略**（让节点能调用外部工具）
5. 如果提示「DSL 版本」相关的确认，直接确认导入。

导入后会进入画布：开始 → 获取今天日期 → 判断老人想做什么 → 四个分支 → 回复。

## 3. 配置模型

1. 左侧点「集成 → 模型供应商」。
2. 找到 **DeepSeek**，填入你的 API Key（在 [DeepSeek 开放平台](https://platform.deepseek.com) 申请）。
3. 想用别的模型，见 [02 更换大模型](02-更换大模型.md)。

## 4. 接入实时数据

助手要查车次、票价、天气、路线，需要再添加两个 MCP 服务：高德地图、12306 查票。步骤见 [04 接入实时数据](04-接入实时数据.md)。

> 不接也能用：此时 Agent 节点调不到工具，助手只能凭常识回答。建议接上，效果差别很大。

## 5. 试运行

点击画布右上角 **预览**，试着输入：

- 11月12日从上海去杭州玩3天，我和老伴两个人
- 下周三从上海到北京有哪些高铁？
- 我住在杭州望湖宾馆，附近有药店吗

画布上会显示每一步经过哪个节点。某个节点变红时，点开它查看错误，最常见的原因是模型 Key 没填、额度用完，或者 MCP 服务器标识填得不对。
