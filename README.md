# 🧓 老人出行小助手（Dify 工作流）

一个面向老年人的 AI 出行助手，基于 [Dify](https://dify.ai) 的 Chatflow 搭建。
导入一个文件，填上自己的大模型，几分钟就能得到一个网页聊天链接，发给家里老人用手机打开即可。

它能帮老人：

- **安排旅游**：节奏慢、少走路、少换乘，每天标出附近医院、药店、厕所和休息点，提醒老年人门票优惠。
- **教买车票、机票**：一步一步教用 12306「敬老版」买票；建议白天出发、直达车次、下铺或靠过道座位。
- **出门前提醒**：按身体情况和季节列出带药和出门清单；遇到胸痛、气喘等急症，第一句话就提醒拨打 120。
- **陪聊和引导**：老人看不懂时，用更简单的话再解释一遍。

> **谁来配置？** 通常是子女、社区或养老机构的工作人员配置一次，再把链接发给老人。老人本人只需要打开链接、打字或说话。

---

## 工作原理

```
用户提问 ──► 获取今天日期 ──► 判断老人想做什么 ──┬─► 写旅游攻略   ──► 回复
                                               ├─► 查票买票指导 ──► 回复
                                               ├─► 出行健康提醒 ──► 回复
                                               └─► 陪聊与引导   ──► 回复
```

- 每个分支都会记住最近 10 轮对话，所以「那后天呢」这样的追问也能接上。
- 所有回答都要求：短句、分步骤、不用英文和专业词。

## 快速开始

1. 注册 [Dify 云版](https://cloud.dify.ai)，也可以[自己部署 Dify](https://docs.dify.ai)。需要 **Dify 1.6 或更高版本**。
2. 下载本仓库中的 [`dsl/elder-travel-assistant.yml`](dsl/elder-travel-assistant.yml)。
3. 在 Dify「工作室」点击 **导入 DSL 文件**，选择这个文件。
4. 配置大模型：默认使用通义千问（`qwen3.6-plus` / `qwen3.6-flash`）。如果手上是别的模型，见 [更换大模型](docs/02-更换大模型.md)。
5. 点右上角 **预览**，试着问一句「下周想坐高铁去北京看孙子，怎么买票？」
6. 没问题就 **发布**，把网页链接发给老人。

## 能做什么，不能做什么

| | 说明 |
|---|---|
| ✅ 能 | 规划行程、讲解买票步骤、出行健康提醒、防骗提醒 |
| ⚠️ 当前版本查不到实时数据 | 不会编造车次、票价、开放时间；涉及这些只说「大概」，并提醒去官方渠道确认。实时数据接入见[路线图](docs/04-接入实时数据.md) |
| ❌ 不能、也不会做 | 替老人登录 12306 或航空公司账号、下单、付款。12306 没有开放下单接口，用程序代登录会违反规定，也会给账号和钱带来风险 |

## 安全与隐私设计

- 助手**从不索要**身份证号、银行卡号、密码、验证码；老人主动发来时，会提醒不要发，也不会在回答里重复这些号码。
- 每次讲买票都会提醒：12306 和航空公司**不会**打电话让人「退票改签」还转账。
- 健康分支声明「不是医生」，涉及换药、调整剂量的问题都建议先问自己的医生；遇到急症，第一句话就提醒拨打 120。
- 本仓库**不包含任何密钥**。每个部署者在自己的 Dify 中填写自己的模型 Key 和服务 Key。

## 自定义

所有提示词都在 Dify 画布的各个节点里，点开节点就能直接修改，比如：

- 在「写旅游攻略」里加上你所在城市的常去景点；
- 在「陪聊与引导」里改称呼，例如称「王阿姨」；
- 在「开始」节点加输入项（常住城市、身体情况、紧急联系人），让每次回答更贴合本人。

改完后可在 Dify 中「导出 DSL」，替换本仓库的 yml，欢迎提交 PR。
